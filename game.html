03 / HOW I BUILT IT

The game is the architecture.

A playable terminal in the browser, connected to a real AWS serverless Hall of Fame. Explore the architecture and its graceful offline fallback.

01 / CLIENT

Browser simulation

Plain JavaScript simulates incidents, command output, checkpoints, badges and share cards. No commands run on a real server.

STAYS PLAYABLE OFFLINE
02 / API

API Gateway

An HTTP API routes leaderboard reads and scores to Lambda, with CORS and rate throttling configured in SAM.

OPTIONAL ONLINE FEATURE
03 / CHECKS

Python Lambda

Validates callsigns and replays the command transcript to calculate server-side scores; a visitor can't simply submit “100.”

ANONYMOUS · NOT CHEAT-PROOF
04 / STORAGE

DynamoDB

Stores top-10 leaderboard entries after validation. If AWS is unreachable, the browser keeps local progress and finishes the game.

GRACEFUL FALLBACK
